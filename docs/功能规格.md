# 文字冒险 RPG 游戏 — 功能规格文档

> 本文档描述 文字冒险 RPG 游戏 的所有功能特性、验收标准与测试策略。
> 与 [CLAUDE.md](../CLAUDE.md) 共同构成本仓的完整规范文档。

## 功能清单

### 核心探索版（text-rpg / `__main__.py`）

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 场景探索 | `go <方向>` / `look` 在场景间移动 | `go north` 后位置变为北向相邻房间 |
| 敌人拦截 | 敌人在场时 `go` 命令无法离开 | 有敌人时 `go` 返回战斗提示，位置不变 |
| 控制平面四环节 | perceive → plan → act → verify 显式拆分 | engine.py 四个方法各自独立调用 |
| 数据驱动场景 | 场景从 `data/scenes/*.json` 加载，无硬编码 | 修改 JSON 后无需改 Python 代码即可生效 |

### 战斗集成版（text-full-rpg / `game.py`）

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 回合制战斗 | 普通攻击 + 技能（耗 MP） | 使用技能后 MP 下降，伤害 > 普通攻击 |
| MP 不足降级 | MP 不足时技能自动降级为普通攻击 | MP = 0 时施放技能返回普通攻击结果 |
| 三职业差异化 | 战士（高 HP）/ 法师（高 MP）/ 盗贼（高攻） | 同一敌人三职业初始属性差异可量化 |
| 物品拾取 | `take <物品>` 将物品加入背包 | 拾取后背包列表包含该物品 |
| 武器装备 | 武器提升攻击力，战斗伤害计算含装备加成 | 有武器时伤害 > 无武器时伤害 |
| 敌人 AI | 敌人有独立 HP / 攻击力 / 技能 | 回合制下敌人可反击，反击伤害 > 0 |

### 存档与读档

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 手动多槽位存档 | `save <slot>` 保存到指定槽位（1-5） | 存档文件写入 `~/.text-adventure-rpg/saves/<slot>.json` |
| 手动读档 | `load <slot>` 从指定槽位恢复 | 读档后位置/背包/HP 与存档内容一致 |
| 自动检查点 | 每 5 个有效回合自动 checkpoint（环形保留最近 3 份） | 自动生成 `auto-checkpoint-<n>.json` 文件 |
| 存档原子写入 | 先写临时文件再 `os.replace` | 不存在半写状态的存档文件 |
| schema_version | 存档文件含版本字段 | 旧版存档可通过版本字段识别 |

### 撤销（Undo）

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 玩家级回退 | `undo` 回退最近 10 步操作 | `undo` 后位置/HP 恢复到上一步状态 |
| 步数限制 | 最多回退 10 步，超出提示无可撤销 | 第 11 步 `undo` 返回「无可撤销操作」 |
| 战斗不可撤销 | 战斗中禁用 `undo` | 战斗中执行 `undo` 返回战斗提示 |

### 动态叙事（Narrative）

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 本地确定性模板 | `client=None` 时走本地模板（零网络依赖） | 无网络环境下 `text-full-rpg` 叙事正常输出 |
| LLM 渲染 | `client` 注入时调用 LLM 渲染场景文本 | 有 client 时输出与本地模板不同 |
| 依赖注入架构 | `NarrationClient` 为 Protocol，后端可替换 | 新增 Narrator 实现类无需改 engine.py |

### 启动自检

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 多文件一致性校验 | 启动时校验 data/ 下 JSON 与代码引用一致 | 校验失败 errors 阻断启动，warnings 放行 |
| 错误可读 | FileNotFoundError / JSONDecodeError 有用户可读提示 | 错误信息不含 traceback 堆栈路径 |

### HTTP API 层（`text-rpg-web` / FastAPI）

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 健康探针 | `GET /api/health` 返回服务与 LLM 模式 | 返回 `{"ok":true,"mode":"mock\|live"}` |
| 职业菜单 | `GET /api/classes` 返回三职业初始属性 | 战士/法师/盗贼 max_hp/max_mp/atk/def 差异可量化 |
| 建局 | `POST /api/games` 创建会话（class/name/scene_id） | 201 返回 `{id,created_at,state}`；非法职业/空名/未知场景 400 |
| 指令执行 | `POST /api/games/{id}/command` 一指令一调用 | 响应 `{messages,state,game_over}`；战斗中仅接受攻击/技能 |
| 存读档 | `POST .../save` / `POST .../load` + `GET /api/saves` | save→load 往返后 HP/MP/场景/战斗状态一致；缺槽位 400 |
| fail-fast 配置 | `LLM_MODE` 必填 mock\|live，禁止兜底默认 | 缺失或非法值启动即报错；live 缺三键报「缺少: …」 |

### Web 前端（`frontend/` React 18 + Vite + TS）

| 功能名称 | 功能描述 | 验收标准 |
| :--- | :--- | :--- |
| 建局态 | 角色名输入 + 三职业属性条对比选卡 | 职业卡数据来自 `/api/classes`，可开新局 |
| 探索态 | HUD（HP/MP 条）+ 场景叙事卡 + 出口按钮 + 指令行 + 存读档 | 出口移动/环视/状态/战斗按钮均驱动后端并刷新视图 |
| 战斗态 | 敌我 HP 对峙 + 攻击/技能按钮 + 战斗日志 | 技能扣 MP，MP 不足后端降级并日志说明 |
| 终局态 | 胜利结算 / 败北遮罩 | 败北后指令禁用，可读档恢复或重选职业 |
| 会话恢复 | localStorage 记住上次会话 id | 服务端会话已清（重启）时自动降级回建局态 |
| 构建门 | `tsc` strict + `vite build` | `npm run build` 零错误通过；同源相对 `/api` 无绝对地址 |
